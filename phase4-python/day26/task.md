# Day 26 — Scientific Visualization: Matplotlib & Seaborn

## Goal
Turn Day 25's findings into clear charts.

## Tasks
Build these 5 charts, each with a title, axis labels, and readable formatting:
1. Bar chart — Total Revenue by Region (Seaborn `barplot`)
2. Line chart — Monthly revenue trend over time
3. Box plot — Revenue distribution by Category (shows outliers well)
4. Heatmap — correlation matrix from Day 25
5. Histogram — distribution of `Quantity`, with a KDE overlay

Save each chart as a `.png` in a `charts/` subfolder.

## Deliverable
`day26_solved.py` + `charts/` folder with 5 saved PNG images.
