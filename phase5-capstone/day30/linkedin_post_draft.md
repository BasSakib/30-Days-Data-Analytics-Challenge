# LinkedIn Post Draft

I just finished a 30-day self-directed data analytics challenge — going
from a raw, messy sales dataset all the way to a full BI dashboard, one
skill at a time. 📊

Here's what the 30 days covered:
• Days 1–7: Excel — formulas, lookups, data cleaning, pivot tables, and
  a full executive dashboard
• Days 8–14: Power BI — data modeling, DAX measures, interactive reports
  with slicers and drill-through
• Days 15–21: SQL — from basic SELECT statements up through window
  functions and query performance tuning
• Days 22–28: Python (pandas, matplotlib/seaborn) — cleaning, EDA, and
  visualization
• Days 29–30: A capstone project tying SQL → Python → BI dashboard
  together end to end

One concrete result from the capstone: after cleaning ~3,000 sales
records (removing duplicates, standardizing inconsistent formatting,
handling missing values), the analysis showed Electronics driving the
largest share of total revenue and the South region outperforming every
other region — the kind of insight that's easy to state but takes real
cleaning and querying work to get to reliably.
