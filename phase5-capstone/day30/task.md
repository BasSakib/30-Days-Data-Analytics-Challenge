# Day 30 — Professional Branding: GitHub Portfolio & Interview Prep

## Goal
Package the 30-day journey into something a recruiter or hiring manager
can actually evaluate in under 2 minutes.

## Tasks

### 1. GitHub repo polish
- Confirm the top-level `README.md` (already in this repo) clearly
  explains the journey, links to each phase, and shows the dataset.
- Add a `LICENSE` file (MIT is a safe default for a portfolio project).
- Make sure every day's `task.md` + solved file is committed.
- Pin this repo on your GitHub profile.

### 2. LinkedIn post
Draft a LinkedIn post announcing the completed challenge. Structure:
- Hook (1 line): what you did and why
- 3–4 bullet highlights (what you built, tools used)
- 1 concrete result/insight from the capstone
- Link to the GitHub repo
- Relevant hashtags (#DataAnalytics #Excel #PowerBI #SQL #Python)

Save your draft as `linkedin_post_draft.md`.

### 3. Interview prep
Prepare answers (written, 3–5 sentences each) for:
- "Walk me through a project you're proud of." (use the capstone)
- "How do you handle messy or missing data?" (reference Day 04/09/24)
- "Tell me about a time you used SQL to answer a business question."
  (reference Day 21)
- "What's a DAX measure you've written and what did it do?" (Day 11)
- "How would you explain a dashboard's insight to a non-technical stakeholder?"

Save as `interview_prep.md`.

## Deliverable
`linkedin_post_draft.md`, `interview_prep.md`, plus a polished repo
(`README.md` + `LICENSE` at the root, confirmed).

## Congratulations 🎉
You've gone from raw CSV to a full analytics stack: Excel → Power BI →
SQL → Python → portfolio. This is genuinely job-ready evidence of skill.
