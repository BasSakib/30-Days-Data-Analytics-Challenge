# Day 14 — Final Deployment: Publish & Share

## Goal
Understand the publish workflow, even without a Pro license.

## Tasks
1. Finalize your report: check every page, remove any test/debug visuals,
   confirm titles and labels are clean.
2. Document the publish steps you'd follow (Power BI Service requires an
   account — write this as a step-by-step guide since publishing itself
   may not be available in your environment):
   - Home → Publish → select workspace
   - Configure a scheduled refresh (if using a file-based source, this
     requires a gateway — explain why)
   - Set up row-level security (RLS) roles if the report had sensitive data
   - Share via link vs. share via App
3. Export your final report as a PDF (File → Export → Export to PDF) as
   your shareable static artifact.
4. Write a short `day14_deployment_notes.md` covering the above steps.

## Deliverable
`day14_solved.pbix` (final polished version) + PDF export +
`day14_deployment_notes.md`.
