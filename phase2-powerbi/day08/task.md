# Day 08 — Power BI Interface & Report View

## Goal
Get comfortable navigating Power BI Desktop and importing data.

## Tasks
1. Open Power BI Desktop, import `data/sales_data_clean.csv`
   (Get Data → Text/CSV).
2. Explore the three views: **Report**, **Data**, **Model**. In a text
   note (`day08_notes.md`), briefly describe what each view is for.
3. In Report view, drop 3 quick visuals onto the canvas just to explore
   the field list: a Card (Total Revenue), a Bar Chart (Revenue by Region),
   a Table (raw rows). Don't worry about styling yet.
4. Rename the report page to "Overview".
5. Save as `day08_solved.pbix`.

## Deliverable
`day08_solved.pbix` + `day08_notes.md` describing the three views.

> Note: `.pbix` files are binary — this solved file is a working starting
> point you open directly in Power BI Desktop.
