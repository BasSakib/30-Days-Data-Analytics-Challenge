# Day 13 — Interactive Reports: Slicers & Filters

## Goal
Make the report genuinely interactive for an end user exploring on their own.

## Tasks
1. Add slicers to the "Sales Story" page:
   - `Dim_Date[Year]` (buttons style)
   - `Region` (dropdown)
   - `Channel` (dropdown)
2. Set up **cross-filtering**: clicking a bar in the Category donut chart
   should filter the line chart and Top 10 SalesRep chart.
3. Add a **drill-through** page: right-click a Region in any chart →
   drill through to a "Region Detail" page showing that region's full
   order table and its own KPI cards.
4. Add a **bookmark**: one bookmark for "Full View" (no filters) and one
   for "Online Channel Only" — add buttons to switch between them.
5. Save as `day13_solved.pbix`.

## Deliverable
`day13_solved.pbix` with working slicers, cross-filtering, drill-through,
and bookmarks.
